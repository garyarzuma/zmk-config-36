## Factorio layer

From the default layer, hold the left middle thumb key (Space/NUM) and tap the
upper-left letter key (Y) to enter the Factorio layer. Tap the far-right thumb
key to return to the default layer. The existing game-layer combo is unchanged.

| Position | Left half | Right half |
| --- | --- | --- |
| Top row | Q W E R T | 6 7 8 9 0 |
| Home row | A S D F G | Z X C V B |
| Bottom row | 1 2 3 4 5 | M H Alt P O |
| Thumbs | Ctrl Space Shift | Esc Enter Default layer |

WASD, inventory (E), pipette (Q), rotate (R), pickup (F), and quickbar slots
1–5 are all reachable with the left hand while the right hand uses the mouse.
The left thumbs provide Ctrl for transfers and shortcuts, Space for shooting,
and Shift for ghost building or reverse rotation. The right half holds the
remaining quickbar slots and less frequent tools and panels. The keys follow
[Factorio's default PC controls](https://wiki.factorio.com/Controls); custom
in-game bindings may need adjustment.
